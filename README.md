## There were two issues with the DOS version of *Lion King* <br> 
**( 1 )** In the menu, the game would jump straight to the ***DEMO-game-mode*** without waiting for the user to press a key. <br> 
This was a bug in the MS-DOS code: because the **delay timing** was originally designed for old MS-DOS systems, <br> 
**the delay** was far too short on modern PCs and x86 Emulators(DosBox), <br> 
causing the game to skip the menu and launch directly into ***DEMO-game-mode*** <br>
***--- BUG FIXED!*** <br>
**( 2 )** There was an issue with jumping when using the arrow keys; <br> 
the default jump key was the SPACE bar. <br>
I have fixed this so that both the SPACE bar and the Up Arrow key function as jump keys <br>
the Up Arrow key wasn't being used for this purpose, but now it works, and Simba jumps when Up Arrow key is pressed. <br>
***--- NEW KEY CONTROL CODE ADDED/FIXED!*** <br>

## ■ Mch2tga: A tool that (1) converts the graphics/sprites of the game *The Lion King* into TGA (Photoshop) format, and (2) converts the image back into the game's original graphics file format after it has been modified. ---(Msdos EXE file) Mch2tga is the FULL version. You can modify all of the game's graphics, with the exception of music and voice files. I am not interested in the audio files (any files that lack an extension and consist only of a name are audio files) or the *.amf music files from The Lion King game; there will be no support for these, and I have no intention of creating a tool for them —so don't wait for one ..
